### Notes
Broica GTK3 is ripped from NsCDE at the time I was tinkering with it. I made the wallpaper specifically for retro styling, but Mars and art belongs to Laika's Comet by FourLeafIsland.

### Requirements
* KDE Plasma
* Commonality (Global Theme and Kvantum)
* Kvantum
* KDE Classic (Came preinstalled)
* nwg-look

### Instructions
As long as these requirements are installed, this can be done by building from source: `git clone https://github.com/soloman28/My-KDE-Dotfiles.git`. Type `Ctrl + H` to show hidden folders, copy all folders mentioned and paste it to your home folder.

### Panel tips
NOTE: You have to select "Dodge windows" on system tray on the bottom right and task icons on the top left.
